# 03 · 设计与交互规范

| 项 | 内容 |
|---|---|
| 风格 | 浅色、干净、克制；深色表盘作为视觉焦点 |
| 参考 | Windows 11 Fluent 的圆角与留白，但不做亚克力/模糊 |
| 目的 | 一眼看懂「现在有没有计划」，两步完成「定个时间关机」 |

---

## 1. 设计原则

1. **状态第一**：用户打开软件，最先要回答的是「我有没有设过」。状态条放在最底部常驻，颜色区分明确。
2. **一个焦点**：整屏只有表盘是深色的，视线自然落在它上面。
3. **不做装饰动画**：除了指针转动，不加任何光效、粒子、呼吸灯。这个工具的目的是「设完就走」。
4. **误操作有代价**：关机不可逆，所以取消要确认、覆盖要确认，按钮层级要分清主次。

### 2.3 规则

- 强调色全局只出现三处：主按钮、指针、已计划状态。不允许给预设按钮上强调色。
- 禁止在浅色背景上用纯黑 `#000`。
- 表盘上的深色底与白色指针对比度 ≥ 8:1。

## 3. 字体

字体族：`"Microsoft YaHei UI", "Segoe UI", "PingFang SC", sans-serif`

| 角色 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 表盘时间 | 40px | Bold | 表盘中央 `23:30` |
| 表盘副标 | 12px | Normal | `今天` / `明天` |
| 标题 | 16px | 600 | 窗口顶部「定时关机」 |
| 正文 | 14px | Normal | 常规内容 |
| 按钮 | 14px | 500 | 所有按钮 |
| 辅助 | 12px | Normal | 状态条、说明文字 |
| 轮盘数字 | 22px | 500 | 时/分滚轮 |

- 数字统一用等宽变体或 `font-feature-settings: "tnum"`（Qt 中通过 `QFont.setStyleHint` + `Monospace` 辅助），保证倒计时跳动时不抖动。
- 中英文之间不加空格，数字与中文单位之间加空格：「剩余 1 小时 20 分」。

## 4. 布局与间距

### 4.1 窗口

- 固定尺寸 `460 × 700`，不可最大化、不可拉伸。
- 内边距：左右 24，上 20，下 20。
- 垂直间距基准 8px，所有间距为 8 的倍数。

### 4.2 结构（自上而下）

```
┌──────────────────────────────┐
│ 定时关机              [状态点] │  56px
├──────────────────────────────┤
│                              │
│          ○ 表盘 280px        │  300px
│                              │
├──────────────────────────────┤
│       [ 08 ] : [ 30 ]        │  132px 轮盘
├──────────────────────────────┤
│ [30分] [1时] [2时] [3时]      │  38px
├──────────────────────────────┤
│        [   设定关机   ]       │  46px
│        [   取消计划   ]       │  36px
├──────────────────────────────┤
│ 当前无计划                    │  36px
└──────────────────────────────┘
```

### 4.3 圆角

| 元素 | 半径 |
|---|---|
| 卡片 / 按钮组 | 16 |
| 常规按钮 | 10 |
| 主按钮 | 12 |
| 状态条 | 10 |
| 轮盘高亮行 | 8 |

### 4.4 阴影

- 主卡片：`0 1px 3px rgba(16,24,40,0.06)`
- 不用多层阴影，不做内阴影。

## 5. 组件规格

### 5.1 表盘（`clock_dial`）

真实双针表盘：**时针短而粗，分针长而细**，两根针的角度都严格由当前时刻决定（时针含分钟造成的偏移）。

| 项 | 规格 |
|---|---|
| 外径 | 280px（含 8px 内缩留白，实际绘制 264px） |
| 刻度 | 60 条小刻度，长 4px / 宽 1px；每 5 条为大刻度，长 8px / 宽 2px |
| 数字 | 1~12，13px Medium，放在半径 `0.74r`（约 98px）处 |
| 分针 | 长 `0.70r`（约 92px），宽 3px，白色，圆头，尾部 7.8px |
| 时针 | 长 `0.48r`（约 63px），宽 5.5px，白色，圆头，尾部 14px |
| 绘制顺序 | 表盘底 → 刻度 → 数字 → 分针 → 时针 → 中心点（时针压在分针上，与真表一致） |
| 中心点 | 半径 6.5px 实心 `accent` |
| 中央文字 | **不放表盘内**，选中时刻显示在表盘上方，34px 600 |
| 进度弧 | **不画**，双针已能表达时刻，弧会与针抢视觉 |
| 焦点态 | 仅 Tab 聚焦时在中心点外画 1.6px `accent` 圈；鼠标点击、窗口激活不显示 |
| 光标 | hover 时 `OpenHandCursor`，拖拽时 `ClosedHandCursor` |
| 键盘 | `←/→` 小时 ∓1，`↑/↓` 分钟 ±1，需先获得焦点 |

#### 5.1.1 表盘的拖拽语义（12 小时 → 24 小时）

按下时先判断用户想动哪根针（与两根针的角度差，容差 18°）：

| 抓到的目标 | 行为 |
|---|---|
| 分针 | **只改分钟**；指针绕一圈，小时 ±1（和拨真表一样） |
| 时针 | **只改小时**，分钟保持不变；绕 12 点翻转上午/下午 |
| 空白处 | 快速定位：两根针一起跳到该时刻，小时取 `h12` 与 `h12+12` 中**离当前最近**者 |

- 拖动过程一律按**角度增量**累计，指针不随光标绝对位置跳变。
- 松手时，分针模式与快速定位模式把分钟吸附到 5 分钟；**时针模式不吸附**（分钟本来就没动，不该被顺手改掉）。
- 已知取舍：12 小时表盘无法直接区分上午/下午，靠「离当前最近」消歧。要精确选定就用轮盘（0~23 直选）。

### 5.2 轮盘（`time_wheels`）

| 项 | 规格 |
|---|---|
| 尺寸 | 宽 200，高 132 |
| 行高 | 44px |
| 可见行 | 3 行（上 1、中 1、下 1），上下边缘渐隐 24px |
| 中间高亮 | 背景 `#F4F5F7`，圆角 8，左右内缩 4 |
| 数字 | 22px，选中项 `text` 色，非选中 `text-disabled` |
| 分隔 | 两列之间 24px 空隙，中间 `:`，颜色 `text-sub` |
| 滚动 | 滚轮 + 拖拽 + 键盘上下键 |
| **方向约定** | **向下滚动 / 向下拖动 = 选「下面」那个更大的数**；向上则相反。滚轮与拖拽必须一致 |
| **滚动动画** | **每列独立**：只有被操作的那一列产生滚动动画，另一列必须静止 |

### 5.3 预设按钮

- 四等分排在 4 列，间距 8，高 38。
- 样式：白底 + `border` 描边，圆角 10，文字 `text`。
- hover 背景 `#F9FAFB`；press 背景 `#F0F2F5`。
- 文案：`30 分` / `1 小时` / `2 小时` / `3 小时`。

### 5.4 主按钮「设定关机」

- 全宽，高 46，圆角 12，填充 `accent`，白色 14px。
- hover `accent-hover`，press `accent-press`。
- 禁用态（理论上不出现）：`#E3E6EB` 底 + `text-disabled` 字。

### 5.5 取消按钮「取消计划」

- 全宽，高 36，圆角 10，白底 + `border` 描边，文字 `text-sub`。
- 无计划时禁用：文字 `text-disabled`，描边 `#EFF1F4`，不可点。
- 有计划时 hover 描边变 `danger`，文字变 `danger`（提示这是破坏性操作）。

### 5.6 状态条

- 全宽，高 36，圆角 10，背景 `#F9FAFB`。
- 左侧 6px 圆点表示状态，右侧文字。
- 三种状态：

| 状态 | 圆点 | 文字 |
|---|---|---|
| 无计划 | `#C9CED7` | `当前无计划` |
| 已计划 | `accent` | `将于 明天 07:30 关机 · 剩余 11 小时 28 分 3 秒` |
| 错误 | `danger` | `操作失败：拒绝访问（返回码 5）` |

- 已计划时「剩余时间」部分加粗。
- 错误状态 3 秒后自动回落到真实状态。

## 6. 交互规范

| 动作 | 反馈 |
|---|---|
| 拖动表盘 | 指针实时跟随，中央数字实时变，松手吸附 5 分钟并轻微回弹（150ms） |
| 滚动轮盘 | 松手 180ms 内吸附到最近行 |
| 点预设按钮 | 直接下发，状态条立即变色，主按钮下方短暂显示「已设定」2 秒 |
| 点设定关机 | 若有旧计划先确认覆盖；成功后状态条变强调色 |
| 点取消计划 | 弹 `QMessageBox` 二次确认，默认焦点在「否」 |
| 关闭窗口 | 直接退出（无托盘）。**不做阻断式确认**：计划由系统内核执行，状态条已常驻显示「将于 X 关机」，再拦一次只会烦人 |

### 6.1 文案规范

- 按钮：动词或名词短语，2~4 个字，不加标点。
- 标题：`定时关机`，不加副标题。
- 提示：陈述句，先说结论再说原因：「无法取消：当前没有待执行的计划」。
- 错误：`操作失败：<原因>（返回码 N）`。
- 禁止：感叹号、表情符号、「亲」「哦」等口语。
- 界面文案集中在 `src/ui/strings.py`，界面代码中不得出现中文字面量。
- 例外：`shutdown` 返回码的中文说明属于领域知识而非界面文案，集中定义在 `src/core/shutdown_service.py` 的 `CODE_MESSAGES`，界面通过 `describe(code)` 取用。

### 6.2 键盘与焦点

- Tab 顺序：表盘 → 轮盘 → 预设 4 键 → 设定关机 → 取消计划。
- 焦点态：2px `accent` 描边，偏移 2px。
- `Esc` 关闭二次确认框，不做其他全局快捷键。

---

## 7. 高 DPI 与适配

- Qt6 默认启用高 DPI，设置 `QGuiApplication.setHighDpiScaleFactorRoundingPolicy(PassThrough)`。
- 所有尺寸使用逻辑像素，不做硬编码物理像素。
- 125% / 150% 缩放下文字不裁切、表盘不变形。

---

## 8. 禁止事项

1. 不使用系统默认控件外观（按钮、滚动条必须 QSS 化）。
2. 不出现渐变按钮、发光、边框阴影叠加。
3. 不在表盘上叠加文字提示以外的任何图形。
4. 不用红色表示「正常」状态。
5. 不做深色/浅色主题切换，固定浅色，减少范围。
