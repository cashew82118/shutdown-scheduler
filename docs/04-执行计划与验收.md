# 04 · 执行计划与验收标准

本文件是**开发过程的唯一进度依据**。任何阶段不得跳步，前一阶段未验收通过，不进入下一阶段。

---

## 0. 推进方式

1. 每个阶段开始前，把该阶段任务写入 `devlog/` 当日文件。
2. 阶段内完成开发与自测。
3. 阶段结束，向用户提交「验收包」：可运行的东西 + 验收清单 + 已知问题。
4. 用户回「通过」→ 记录到 devlog，进入下一阶段。
5. 用户指出问题 → 只修当前阶段，修完重新提交验收，不顺手改下一阶段的东西。

---

## 1. 阶段总览

| 阶段 | 名称 | 产出 | 依赖 |
|---|---|---|---|
| P0 | 环境与骨架 | 可运行的空白窗口 + 全部规范文件 | 无 |

## 3. P1 · 关机指令层

**目标**：把「设定 / 查询 / 取消」做成可靠、可单独验证的能力，先于界面存在。

### 任务

- [x] `src/core/clock_math.py`
  - `resolve_target(now, hour, minute) -> Target(moment, is_next_day)`
  - `seconds_until(target, now) -> int`，clamp 到 `[60, 315360000]`
  - 内置断言自测：跨天、恰好 60 秒、23:59 → 次日（10 项）
- [x] `src/core/plan_store.py`
  - 路径 `%LOCALAPPDATA%\ShutdownScheduler\state.json`
  - `save / load / clear`，原子写入（tmp + os.replace）
  - 损坏文件容错
- [x] `src/core/shutdown_service.py`
  - `arm(seconds) -> Result(ok, code, message, output)`
  - `cancel() -> Result`
  - 返回码映射：0 / 5 / 1116 / 1190，另有 `CODE_MESSAGES` 与 `describe(code)`
  - OEM 编码解码，`CREATE_NO_WINDOW`，不传 `/f`
- [x] `scripts/selftest_shutdown.py` + `scripts/selftest.bat`
  - 以 **600 秒** 下发 → 读本地记录 → 取消 → 再取消一次验证返回 1116
  - 输出逐步 PASS/FAIL，`finally` 兜底取消，最后打印「系统当前无待定关机」

### 验收清单（用户执行）

- [ ] 双击 `scripts/selftest_shutdown.py`（或运行对应 bat），看到 5 行 PASS
- [ ] 脚本结束时，系统没有任何待定关机（可用自己再跑一次取消命令确认）
- [ ] 整个过程没有真的关机

### 安全铁律（本阶段起永久生效）

1. 任何测试的倒计时 **不得少于 600 秒**，脚本中禁止出现小于 60 的字面量。
2. 每次测试结束必须执行取消，并确认返回 1116。
3. 禁止使用 `shutdown /f`。
4. 一个测试周期内不叠加多个计划。
5. 命令行测试统一带 `CREATE_NO_WINDOW`，避免弹黑框影响用户。

## 4. P2 · 表盘与轮盘

**目标**：把「选时刻」这件事做得直观，先独立成 demo，不接关机逻辑。

### 任务

- [x] `src/ui/clock_dial.py`
  - 自绘**真实双针**表盘：底（径向渐变）、60 刻度、1~12 数字、分针（长细）、时针（短粗）、中心点
  - 三种拖拽模式：抓分针改分钟（绕圈小时 ±1）、抓时针改小时（分钟不动）、点空白快速定位
  - 拖拽按角度增量累计，不随光标绝对位置跳变
  - 键盘微调；焦点环只在 Tab 聚焦时出现
  - 信号 `timeChanged(int, int)`（用 hour/minute 两个整数，避免 QTime 在 24 点边界上的歧义）
- [x] `src/ui/time_wheels.py`
  - 时/分两列，行高 44，居中吸附，上下渐淡，滚轮/拖拽/键盘三种输入
  - **每列独立的滚动动画**，互不干扰
  - 信号 `timeChanged(int, int)`
- [x] `src/ui/clock_demo.py`（联动 demo，长期保留，用于回归与手感检查）
  - 表盘在上、轮盘在下，双向联动（`set_time` 不发信号，避免循环）
  - 顶部显示 `今天 08:30` / `明天 07:30`，跨天用强调色
- [x] 辅助脚本：`scripts/smoke_demo.py`（截图）、`scripts/test_interaction.py`（21 项交互回归）、`scripts/run_clock_demo.bat`

### 验收清单（用户执行）

- [ ] 双击 demo，表盘上能看到**两根针**：短粗的是时针、长细的是分针

- [ ] 拖**时针**：只有小时变，分钟保持不变
- [ ] 点表盘**空白处**：两根针一起跳到该时刻，松手后分钟停在 5 的倍数

- [ ] 把时间调到早于当前时刻，顶部显示「明天」

## 8. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| PyQt6 下载失败 | 阻塞 P0 | 换镜像源 / 换 pip 版本 / 降级到 PyQt5 |
| 打包时 bootloader 下载失败 | 阻塞 P4 | 先用 `--onedir` 交付，后续补 onefile |
| `shutdown` 权限不足 | 功能不可用 | 提示以管理员运行；P1 阶段先实测确认普通账户可用 |
| 表盘拖拽手感差 | 体验不达标 | 调整吸附阈值与回弹时长，必要时改为「点击刻度」 |
| 本地记录与真实状态不一致 | 显示误导 | 界面标注「本软件记录」，P4 后评估是否加只读探测 |
