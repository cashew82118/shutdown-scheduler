# 02 · 技术方案

| 项 | 内容 |
|---|---|
| 语言 | Python 3.13 |
| GUI | PyQt6（Qt 6.x） |
| 打包 | PyInstaller（onefile + windowed） |
| 平台 | Windows 10 / 11，x64 |
| 权限 | 普通用户，无需管理员 |

---

## 1. 选型理由

- **PyQt6**：原生窗口、启动快、体积可控；`QPainter` 画表盘自由度高，指针拖拽由鼠标事件直接驱动，不需要额外的动画框架。
- **不用 Web 技术栈**：避免引入 WebView2 依赖与 100MB+ 的运行时体积。
- **不用 tkinter**：自绘表盘与平滑指针在 tkinter 上观感明显吃力。
- **不引入第三方 UI 库**：样式全部用 QSS + 自绘，减少依赖与打包风险。

## 3. 模块职责

| 模块 | 职责 | 不允许做的事 |
|---|---|---|
| `clock_math` | 纯函数：把 (时, 分, 当前时间) 换算成目标时刻与秒数 | 不碰 UI、不碰 subprocess |
| `plan_store` | 读写 `state.json`，处理损坏与过期 | 不执行命令 |
| `shutdown_service` | 拼参数、执行 `shutdown.exe`、解析返回码 | 不做界面提示，只返回结构化结果 |
| `clock_dial` | 绘制表盘、处理鼠标拖拽、吸附、发出时间变更信号 | 不直接设关机 |
| `time_wheels` | 两列滚轮、吸附居中、发出时间变更信号 | 不直接设关机 |
| `main_window` | 组装界面、串联业务、二次确认、状态刷新定时器 | 不直接调 subprocess |

**分层红线**：UI 层只能调用 `shutdown_service` 与 `plan_store` 的公开方法，不得出现 `subprocess`、`shutdown` 字样。

## 4. 关键实现

### 4.1 调用 shutdown

```python
subprocess.run(
    ["shutdown", "/s", "/t", str(seconds)],
    capture_output=True,
    creationflags=subprocess.CREATE_NO_WINDOW,  # 不闪黑框
    timeout=10,
)
```

- 必须带 `CREATE_NO_WINDOW`，否则打包成窗口程序后仍会闪出控制台。
- 输出按系统 OEM 编码解码：`locale.getpreferredencoding(False)`，失败时 `errors="replace"`。中文系统下为 GBK，用 UTF-8 会乱码。
- 返回码映射见 `01-需求规格.md` §5.2。
- **覆盖必须两段式**：系统拒绝直接覆盖（返回 1190），因此「替换已有计划」= 先 `/a` 再 `/s /t`。两段之间失败要单独提示，不能让用户以为新计划已生效。

### 4.2 时间与跨天

```python
def resolve_target(now: datetime, hour: int, minute: int) -> tuple[datetime, bool]:
    target = now.replace(hour=hour, minute=minute, second=0, microsecond=0)
    next_day = False
    if (target - now).total_seconds() < 60:
        target += timedelta(days=1)
        next_day = True
    return target, next_day
```

- 剩余时间每次从 `datetime.now()` 重算，不做秒数累加（防止系统时间调整导致漂移）。
- 秒数向下取整，最小 60，最大 315360000。

### 4.3 本地计划记录

路径：`%LOCALAPPDATA%\ShutdownScheduler\state.json`

```json
{
  "version": 1,
  "target_ts": 1793260800,
  "target_text": "2026-10-22 07:30",
  "created_at": 1793200000,
  "seconds": 60800,
  "source": "wheel"
}
```

- 写入用「临时文件 + `os.replace`」原子替换，避免写一半断电损坏。
- 读取异常（不存在、JSON 破损、字段缺失）一律视为无计划，并记日志。
- 启动时若 `target_ts <= now`，直接清除。

### 4.4 表盘绘制

- `QWidget.paintEvent` + `QPainter`，开抗锯齿。
- 层次：表盘底（径向渐变）→ 60 刻度 → 1~12 数字 → 分针 → 时针 → 中心圆点。时针压在分针上，和真表一致。
- 两套角度函数：时针 `(hour % 12) * 30 + minute * 0.5`，分针 `minute * 6`。以 12 点方向为 0°，顺时针。
- 命中区域：距圆心 20px 到半径之间。
- **拖拽分三种模式**，按下时按「光标与两根针的角度差」判定（容差 18°）：抓分针 → 只改分钟、绕圈小时 ±1；抓时针 → 只改小时、分钟不动；点空白 → 快速定位，两针一起跳。
- 拖动过程按**角度增量**累计（不是绝对定位），否则按下瞬间的定位会污染后续判定，同一位置能拖出不同小时——这是 P2 踩过的坑。
- 松手吸附 5 分钟只作用于「分针模式」和「快速定位」；时针模式不吸附，否则会顺手改掉用户的分钟数。
- 动画：`QVariantAnimation` 0→1 驱动两根针同时插值，各自取最短路径（避免从 350° 转到 10° 时绕大圈）。
- 长时间拖拽不做节流，Qt 的鼠标事件频率足够；绘制本身为纯 2D 图形，开销可忽略。

### 4.5 滚轮

- 用两列 `QListWidget`，固定行高 44px，`setVerticalScrollMode(ScrollPerPixel)`。
- 通过监听垂直滚动条的 `valueChanged`，把「距中心最近的项」作为当前值，并 `scrollToItem(item, PositionAtCenter)` 吸附。
- 上下各绘制 2 项，边缘用 `QGraphicsOpacityEffect` 或绘制遮罩做渐隐（首选绘制遮罩，避免每个 item 挂特效导致卡顿）。

### 4.6 联动与防抖

- 表盘与滚轮各自暴露 `timeChanged(QTime)` 信号。
- 联动时先 `blockSignals(True)` 设置对方值，再恢复，避免 A→B→A 循环。
- 主窗口持有唯一的「当前选择时间」状态，两个控件都只是它的视图。

### 4.7 状态刷新

- `QTimer` 间隔 1000ms，只在「存在计划」时启动，避免无谓唤醒。
- 每次 tick 重新读取 `datetime.now()` 计算剩余，不依赖 tick 计数。

### 4.8 单实例

- `QLocalSocket` / `QSharedMemory` 检测，已存在则向已有实例发送激活消息并退出。

## 5. 打包

```
pyinstaller --noconfirm --onefile --windowed ^
  --name 定时关机 --icon assets/app.ico ^
  --add-data "assets;assets" src/main.py
```

- `--windowed` 去掉控制台窗口。
- 首次打包会下载 bootloader，若网络失败，改用 `--onedir` 输出目录版作为过渡方案。
- 产物放 `dist/定时关机.exe`。
- 打包后需实测：无 Python 环境的机器上双击可运行（本机先验证路径与资源加载）。

## 6. 日志

- `logs/app.log`，`logging.handlers.RotatingFileHandler`，单文件 1MB，保留 3 份。
- 记录：启动、设定成功/失败（含返回码）、取消、状态恢复、异常堆栈。
- 打包后日志目录取 `exe` 同级 `logs/`；开发期取项目根 `logs/`。
- 不记录用户无关信息，纯本地。

## 8. 已知技术限制

1. **无法查询系统级待定关机**（见需求 §5.3），状态以本地记录为准，界面如实标注。
2. `shutdown /s /t` 的计划在 Windows 重启/关机后失效，属于系统行为，不做补偿。
3. 提前自动保存（如 Office 文档）不在本工具能力范围内，不承诺「无损关机」。
